# Summary

Requirements for a magic based battle royale.

# Character behaviors

- multiple attack types
    - long range
    - short range
- multiple defense types
    - directed shield
    - 360 shield
- mana system
    - different attacks and defenses have different costs.

# Game behaviors

- configurable game settings.
    - choose game time
    - select random map seed ?
- Game mode select screen
- leaderboard
- one or more playable characters
    - single player
    - multiplayer
- one ore more non playable characters
    - npc allies
    - npc opponents
- deathmatch style gameplay
- free for all.
- ranking system.

# Map behaviors

- Randomly generated
- areas for player to take cover
- clear boundaries

# Time behaviors

- configurable timed matches
- match lasts until last enemy player is elimanted
- match lasts until time runs out
